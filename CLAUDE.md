# PestiAlvilag code map

A 1932 Budapest GTA 3 style game. Unreal 5.8.4, C++ only: almost everything is built in code at runtime, the levels are nearly empty.
Read this first. Open only the files your task needs, and grep big files instead of reading them whole.

## Where things start
- `Source/PestiAlvilag/PestiAlvilagGameModeBase.cpp` spawns every system (world, traffic, people, missions, landmarks). Start here to find who owns what. `PestiStart` holds start spots and yaws.
- Map data comes from `Tools/OsmGraybox/` (Python): `osm_to_graybox.py` (streets, blocks; reads `source/blaha_test_area.osm` plus `source/east_strip.osm`, the strip east to the trotting track cut by `east_strip.py`, and adds its 1932 houses, track infield and gallop field in east_1932), `street_furniture.py` (lamps, benches, pavements, shops, walker lines), `trams_1932.py` (tram lines), `buses_1932.py` (bus lines), `city_details.py` (open courtyards, Corvin, wall adverts, kiosks, clocks, map icons). Output JSON lives under `Data/` and is read by `OsmGraybox.cpp`, `StreetFurniture.cpp`, `Pedestrians.cpp`, `Knockables.cpp`.

## Naming pattern
- `*Model.h` (namespace, header only): builds the boxes/shapes of one thing (CarModel, PersonKit, TramModel, ShopModel, MarketHallModel...). Change looks here.
- `*Synth.h` + `*Sound.cpp`: sounds made in code (EngineSound, TramSound, HorseSound, FightSound).
- The matching `.cpp/.h` actor holds behaviour.

Lean per car: CarHandling RollShare.
  Handling and crash physics: `CarHandling.h` (each EBody's weight, top speed, pull, brakes, steering, grip, gear change time as shares of the saloon; Collide: momentum and spin trade between two cars or a car and a wall).
